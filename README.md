# Parakeet

Parakeet is an application that can send and receive messages to and from other clients using the parakeet application. 

We will be using AWS' DynamoDB  to serve as a backend. 
The app will send messages and files to the cloud, and other users with the app will be able to see the messages appear on their app, and download the files that were sent. 
The app will be written in Java, via VSCode. 

Required features to be added:
- file sending
- create accounts
- messaging between two users
- chatrooms

Misc features to be added:
- sound played when receiving/sending messages
- messaging between more than two users
- customize color of message boxes
- customize color of font
- customize font
- customize color of background
- option to set image as background
- timestamp of message
- better postion of user name
- etc...
